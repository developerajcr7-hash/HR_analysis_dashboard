Sales Performance Dashboard – Power BI

📊 Project Overview

This project is an interactive Sales Performance Dashboard developed using Microsoft Power BI.

The dashboard analyzes sales performance, revenue, targets, customer activity, and sales trends to help understand business performance.

🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

📌 Key Analysis

- Total Sales
- Total Revenue
- Number of Orders
- Sales Target Achievement
- Sales by Region
- Sales by Product
- Monthly Sales Trends
- Salesperson Performance
- Conversion/Performance Analysis

📈 Dashboard Features

- Interactive filters and slicers
- KPI cards
- Sales trend analysis
- Regional analysis
- Product performance
- Salesperson performance
- Interactive charts and tables

🔄 Data Preparation

Data was cleaned and transformed using Power Query.

The following activities were performed:

- Removed duplicate records
- Handled missing values
- Corrected data types
- Created calculated columns
- Created relationships between tables
- Prepared data for analysis

🧮 DAX

Some measures were created using DAX for calculating business KPIs such as:

- Total Sales
- Total Orders
- Average Sales
- Target Achievement %
- Monthly Sales

📂 Project Files

- "PowerBI/Sales_Performance_Dashboard.pbix" – Power BI dashboard
- "Dataset/sales_data.xlsx" – Dataset used for analysis
- "Screenshots/dashboard.png" – Dashboard preview

🎯 Objective

The objective of this project is to analyze sales data and provide an interactive dashboard that helps users monitor sales performance and identify important business trends.
